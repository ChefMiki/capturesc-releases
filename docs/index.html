NewSnipito 0.2

A new name, a new look, and an editor.

  • Editor. Crop, add a background, drop in another image, save as a project and keep editing later.
  • Scrolling capture. Select the part of a page that scrolls; Snipito stitches one tall picture.
  • Copy text. Select any area and its text lands on your clipboard.
  • Right-click in File Explorer. Edit with Snipito, Pin to screen, Copy text and Add background for any picture.
  • Color picker and ruler. Press C for a color, M to measure while selecting.
  • Updates from inside the app. Open What's new and click Check for updates. Snipito asks before it goes online.

Install in a minute.

  1. Unzip the downloadAnywhere you like, for example your Downloads folder.
  2. Double-click Install.cmdClick Yes when Windows asks. It installs Snipito and starts it.
  3. Press Print ScreenSnipito waits in the tray next to the clock.
Coming from CaptureSC 0.1? Snipito is the same app under its new name. Install it over the old one; your screenshots and settings stay. From now on it updates itself.
About Smart App Control This preview is not code-signed yet. If Smart App Control is on, Windows may block Snipito. The installer checks for you and explains how to turn it off in Windows Security, under App & browser control.

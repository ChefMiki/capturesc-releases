  1. Unzip the downloadAnywhere you like, for example your Downloads folder.
  2. Double-click Install.cmdClick Yes when Windows asks. It installs CaptureSC and starts it.
  3. Press Print ScreenCaptureSC waits in the tray next to the clock.
